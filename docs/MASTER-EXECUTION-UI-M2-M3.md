> Gộp 3 mặt trận vào 1 lộ trình execute. Lý do gộp: M2 + M3 đều ĐẺ thêm UI (tab Kết nối, panel persona-chat, tab Kỹ năng) → phải nằm trong cùng bộ redesign "Chat Cockpit" + chung 1 THEME. Detail từng task ở 3 doc con.

## §A. UI THEME — chốt TRƯỚC (cross-cutting cho mọi task UI)

**Triết lý (bám NORTH_STAR):** dark token-based · premium · power-user · KHÔNG "AI slop" · galaxy là nhân vật chính.

### THEME CHỐT: "JARVIS COCKPIT" — Glass-minimal (nền) × Jarvis hero (điểm nhấn)
Nền = glass minimalism + hover-reveal (dễ build, sạch, dùng cả ngày); điểm nhấn = chất Iron Man/Jarvis ở galaxy/persona/dashboard.
- **Nền:** space-navy gần đen `#05070e` → panel **glass** (rgba + backdrop-blur), viền mảnh `rgba(120,200,255,.12)`, bóng mềm, nhiều khoảng trắng.
- **Màu:** cyan/teal `#22d3ee` (chính, glow) + amber/gold `#f5b54a` (Iron Man warm — "live"/thị trường/tiền) + danger rose `#fb7185`. (cyan+gold = đúng 2 màu Iron Man.)
- **Chữ:** Inter (UI) + JetBrains Mono cho SỐ/token/data.
- **Tương tác:** PROGRESSIVE DISCLOSURE — mặc định sạch, chi tiết/nút *hiện khi hover* (desktop); mobile → tap/nút hiện sẵn (lo ở T1 responsive).
- **HERO (Jarvis chất):** galaxy + persona + dashboard → lõi **arc-reactor** sáng, **vòng HUD xoay** quanh quả cầu, gold+cyan glow, particle nhẹ.
- **Work area (calm):** chat/tab/bảng → glass tĩnh, glow nhẹ, đọc dễ. Motion êm, KHÔNG chớp nháy.
- **Build:** đa số CSS/Tailwind (nhẹ GPU) cho glass+hover; Jarvis hero dùng three.js (galaxy đã có).
