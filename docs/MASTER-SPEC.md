## PHẦN I — NORTH-STAR: Lucy = Jarvis (5 trụ, đã chỉnh)
1. **Một bộ não — self liên tục**: mọi tương tác (chat/agent/cron/market/code) bồi vào CÙNG context sống về Bill. Nhớ liền mạch ("hôm qua anh làm X…"), không bắt đầu lại.
2. **Một presence, nhiều mặt**: Telegram/Hub/Discord/voice = cùng 1 Lucy, cùng context, liền mạch giữa thiết bị.
3. **Orchestrator-of-self + MINH BẠCH** *(chỉnh)*: Lucy điều phối sub-agent expert; cuộc nói-chuyện-với-agent HIỆN INLINE trong chat dạng **card kiểu bash-tool** (collapse) — Bill thấy Lucy gửi gì cho agent + agent trả gì. Vẫn 1 luồng chat, không phân mảnh, nhưng KHÔNG giấu cơ chế (Bill xem được khi muốn).
4. **Awareness EVENT-DRIVEN** *(chỉnh)*: KHÔNG poll real-time (tốn token). Lucy **tự viết code watcher/hook** (detector nhỏ: lỗi code, deploy fail, ngưỡng giá…) chạy nhẹ/cron, chỉ **PING Lucy khi có sự kiện** → Lucy mới check. Dream chạy đêm. Chủ động nhưng không ồn.
5. **Inward — hiểu Bill sâu** *(CORE/vision)*: học pattern, đoán nhu cầu, continuity, quan hệ sâu dần. Trợ lý cá nhân thật. vault + dream + Context/USER.md = self sống.

## PHẦN III — CORE FEATURE (các chi thể interlock thành 1 hệ)

- Conversation store harness-owned (J1) — nguồn sự thật hội thoại.

### CF-2. Universal Model+Tool Layer = Hermes parity (L + M)
- **L (context portability)**: provider-agnostic request builder → MỌI model (Claude/lane free) nhận CÙNG persona+history → đổi model không đứt mạch. + compressor (E1) ép dưới trần ctx. + catalog scrape (model nào ở nền tảng nào).
- **M (tool harness)**: MỌI model có tool thống nhất (file/bash/**web_fetch/web_search**) + agentic loop → free model = agent KHÔN (research/task dài). Capability-aware routing.
- → Bỏ băng-dán D7. Free model vừa khôn vừa liền mạch.

### CF-3. Orchestrator-of-self + Transparent Multi-agent (K + #3)
- Lucy nhận 1 câu → tự quyết: trả thẳng / hỏi sub-agent expert (persona+skill+brain riêng) / kích autopilot / check market → DỆT về 1 luồng.
- Persona THẬT đa lĩnh vực (dev/marketing/UX/finance/research…), mỗi persona = systemPrompt + skill + **brain riêng (ĐÃ CÓ `Brain/agents/*.md`)**.
- **Minh bạch (#3)**: mỗi lần consult expert → card inline trong chat (gửi gì / nhận gì), collapse. Tái dùng tool-card UI (Section A).
- **Visual brain từng agent (K3)**: thêm `Brain/agents` vào galaxy + view riêng.

### CF-4. Event-driven Awareness (#4)
- Lucy tự viết detector (script/hook/cron nhẹ) cho thứ đáng theo dõi → chỉ ping khi có event → Lucy check. KHÔNG poll real-time.
- Dream đêm (consolidate + prune ✅) + cron lọc tin xàm (Track 4b) chạy nền.
- Chủ động surface đúng lúc, lọc nhiễu mạnh (không spam).

### CF-5. Jarvis UI (Phase N)
- Hội thoại-trung-tâm + orbit + Home-of-Lucy sống (Phần II). Multi-agent card (#3) + galaxy + market panel theo ngữ cảnh.

- **BH-F. Chuyên sâu THỊ TRƯỜNG (sở trường Bill)** ⭐: watchlist real-time + cảnh báo ngưỡng (giá/RSI/funding) · research-agent backtest · sentiment tin tức → Lucy = quant assistant, không generic.
- **BH-G. ĐÁNG TIN & quan sát**: execution replay + explainability ("vì sao Lucy làm X") · self-healing (stuck → tự vá/decompose) · confidence + nguồn + giờ trên mọi câu thị trường.
- **BH-H. Ecosystem**: multi-platform (Discord/WhatsApp như team member) · voice in/out (khi nâng máy) · image/chart understanding (đọc screenshot biểu đồ, tự vẽ chart) · persona registry UI (K4).
